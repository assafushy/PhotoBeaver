# M4 manual tests: cloud and export connectors

SPEC 12 M4 acceptance asks for a manual test of each connector against a real account or archive. Run these on a build of the `m4-connectors` branch (`pnpm dev` is fine). Record the date, the app version and any problems next to each step.

Before you start, register your own apps by following each plugin's README:

- Dropbox: `plugins/connector-dropbox/README.md`
- OneDrive: `plugins/connector-onedrive/README.md`
- Google Photos: `plugins/connector-google-photos/README.md`

Then open **Plugins**, open each plugin's **Settings** and paste its client ID (and the client secret for Google).

## Dropbox

1. Put the same photo in a local folder source and in your Dropbox.
2. Sources > Add source > Dropbox > Add. The browser opens the Dropbox sign-in page. Approve it.
3. The dialog closes and the source shows "Dropbox (your email)". The grid fills with your Dropbox photos.
4. Open a Dropbox photo in the viewer. It loads, and "Open in source" opens dropbox.com.
5. The photo that is in both places shows as **one** item with **two** locations in the info panel.
6. Add a photo to Dropbox, click **Sync now**. It appears. Delete it in Dropbox, **Sync now**. It disappears.
7. On dropbox.com > Settings > Connected apps, disconnect the app. Click **Sync now**. The source shows "Needs reconnecting" with a **Reconnect** button.
8. Click **Reconnect**, approve in the browser. The source syncs again.
9. Start adding another Dropbox source and click **Cancel** while it waits for the browser. No source is added.

## OneDrive

1. Sources > Add source > OneDrive > Add, sign in with a personal Microsoft account.
2. Check steps 3 to 8 of the Dropbox list (revoke access at account.live.com/consent/Manage).
3. Repeat with a work or school account if you have one, and with a folder set in the source config.
4. Check the plugin log (Plugins > OneDrive > View logs) for any "not allowed" network errors on downloads or thumbnails.

## Google Photos

1. Picker: Sources > Add source > Google Photos, mode **picker**, Add, approve in the browser.
2. Click **Sync now**. The Google Photos picker opens in the browser. Pick a few photos and a video, click Done.
3. The items appear with dates. Opening one shows the 1024 px preview. Wait an hour, restart the app, and check they still display.
4. Takeout: request a Google Photos export from takeout.google.com (.zip, any size). Add a Google Photos source in **takeout** mode pointing at the folder with the downloaded zips (do not unzip).
5. Photos appear with capture dates, places and album names. A photo in an album appears once.

## Facebook export

1. Request "Download your information" in JSON format with High media quality. Download the zip parts into one folder.
2. Add a Facebook export source pointing at that folder.
3. Photos and videos appear with their dates. Captions with accents and emoji show correctly. Album names appear. Photos with location show on the Map.

## Instagram export

1. Request the Instagram data download in JSON format with High quality.
2. Add an Instagram export source pointing at the folder with the zip.
3. Posts, carousels, reels, stories and profile photos appear with dates and captions.
