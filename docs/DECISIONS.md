### Follow-ups from the M0 review (2026-10-03)

- **D14:** the grid orders by `COALESCE(captured_at, 0)` but the index is on plain `captured_at`, so SQLite cannot use it and sorts the whole table on every page. Add a matching expression index. Using `0` for undated assets also sorts pre-1970 photos below undated ones; use the minimum integer instead.
- **D10:** consider `NOT NULL` on `plugin_kv.value_json`, with deleting a key removing the row, so plugins never see a stored null that differs from a missing key. Cheapest before the first release, since SQLite needs a table rebuild to add the constraint later.
- **D17:** `PB_USER_DATA_DIR` is honored in packaged builds. Consider applying it only when `!app.isPackaged`.
